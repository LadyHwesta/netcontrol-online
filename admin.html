ENABLE A LANGUAGE

Enabling a language installs its argos-translate model server-wide (shared with any other organization that also uses it — no duplicate downloads) and pre-translates the app's known UI strings in the background — this can take a while the first time a given language is enabled on this server. Any argos-translate-supported language code works (e.g. es, fr, de).

LOGIN SCREEN MESSAGE

Shown to everyone on the login screen, before they sign in. Leave blank for none.

POST-LOGIN WELCOME POPUP

Shown as a dismissible popup right after signing in. Each user sees it once per message — editing the text makes it pop up again for everyone. Leave blank for none.

MOVE A USER

Moves a user into a different organization — removes their membership in every other organization they belong to.

ADD USER TO ANOTHER ORGANIZATION

Adds a user to an additional organization without touching their existing memberships — for an operator who legitimately needs to work across more than one org.

MOVE A NET

Moves a net (with its sessions and history) into a different organization. Ownership and sharing are left unchanged.

REASSIGN NET OWNER

Changes who owns a net. The new owner must already be an approved member of the net's organization.
