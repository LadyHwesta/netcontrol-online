PRIVACY POLICY

Last updated 2026-09-07

Who runs this

NetControl Online is free, open-source software (GPLv3) that clubs, ARES sections, and GMRS groups download and run on their own server — this install is one such copy. The organization running it, not the software project, is the one holding your data and responsible for it. If you're not sure who that is for the site you're on, ask whoever invited you to register, or use the Report / Request page after logging in.

Information we collect

Account information — callsign, name, email address, and the password you choose (stored only as a one-way hash — nobody, including an admin, can recover the original). Phone number and GMRS callsign are optional, provided by you.

Organization information — if you found a new organization, its name and website are visible to the admin approving your registration and, if you opt a net into the public directory, to the public.

Net and check-in data — the callsign, name, signal report, and comments logged for each check-in; whether you're carrying traffic; and, during an Activation & Incident Response session, your reported evacuation zone and — only if you or your net's APRS integration provides it — a GPS position. Manual position entry is opt-in per check-in; APRS-derived positions only appear for a net an admin has specifically configured to track them.

Uploaded files — a profile photo, if you add one, and an organization logo, if an admin uploads one.

Device information — if you enable browser push notifications, the subscription your browser generates (not tied to your identity beyond your account) and a general browser/OS string, so a reminder can be delivered to that device. Your login session is a token kept in your browser's local storage, not a tracking cookie — nothing about your visit is shared with anyone else through it.

Anything you send us directly — a bug report or feature request submitted through the Report / Request page, or a message to support.

How it's used

To run the net check-in log itself; to email you about account approval, password resets, and (if you opt in) new registrations or upcoming shifts; to send a push notification if you've enabled one; and to respond to reports you send us. We don't sell data, and we don't use it for advertising — there isn't any advertising here.

Services this app may talk to

Only the pieces your organization's admin has actually turned on send anything outside this server:

  • Outgoing email — sent through whatever mail provider the operator configured (e.g. Gmail, SendGrid), which sees the message like any email provider would.
  • Bot-check widget, if enabled on registration/login — Cloudflare Turnstile or Google reCAPTCHA, each under its own privacy policy; or ALTCHA, which runs entirely on this server and contacts no one.
  • aprs.fi, only for a net an admin has connected to it — your callsign is sent to look up its last reported APRS position.
  • The Fediverse, only if an admin turns on ActivityPub federation for this organization — net/session updates are then published publicly to whoever follows that organization's feed.
  • The community Net Repository, only for a net an admin opts into the public directory — this shares that net's name, frequency, and schedule, never check-in rosters or personal data.
  • Public amateur/GMRS license lookups (FCC ULS, HamDB, callook.info) — used to look up publicly-available license information for a callsign you search, and cached locally to avoid repeat lookups.

How long we keep it

Net and check-in history is kept indefinitely by default, since it's the operating log the software exists to maintain — an admin can delete individual sessions or check-ins at any time. Deleting your account removes your profile; check-ins you logged stay attached to the net's history under the callsign you used, the same way a paper net log would.

Your choices

Update your name, phone, photo, and notification preferences any time from Account. Ask your organization's admin to correct, export, or delete your account — or, if you're the only admin, use the Admin panel yourself. Browser push and email notifications are opt-in and can be turned off from Account at any time.

Children's privacy

This app is built for licensed radio operators and isn't directed at children. We don't knowingly collect information from anyone under 13.

Security

Passwords are hashed, never stored or emailed in plain text. Long-lived API tokens are only ever shown once, at creation. No system is perfectly secure, but there's nothing here designed to be sold or mined — it's a net log, not a data business.

Changes to this policy

If this policy changes in a meaningful way, the "Last updated" date above will change too. Because this is self-hosted software each operator runs independently, check with your specific organization's admin if you have questions about how they've configured it.
